## Quick Reference

**Environment Variable:** `AZURE_CREDS`

**Supported Formats:**
- JSON
- Base64-encoded JSON
- File path

**Example:**
```json
{
  "client_id": "CLIENT_ID",
  "client_secret": "CLIENT_SECRET",
  "tenant_id": "TENANT_ID",
  "subscription_id": "SUBSCRIPTION_ID"
}
```

For now, see the [general authorization guide](../authorization.md) for credential format examples.
